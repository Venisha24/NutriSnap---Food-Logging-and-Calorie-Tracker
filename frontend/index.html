    AI behind NutriSnap

    A real Vision Transformer, not a lookup toy

    Classification runs on-device in the Flask backend with ViTForImageClassification. The network splits the photo into 16×16 patches, encodes them with 12 transformer layers, and outputs a softmax over 80 Indian food classes from the Kaggle Indian Food Images Dataset.

    1. Preprocess Resize to 224×224 and normalize.
    2. ViT backbone Patch embeddings + self-attention.
    3. Softmax head Predicted class + confidence.
    4. Nutrition table Macros from the 2025 Indian food nutrition dataset.
    5. OpenRouter Optional 2-sentence coaching note. If ViT confidence is low, a vision model may confirm the class. This is the only API key in the project.
